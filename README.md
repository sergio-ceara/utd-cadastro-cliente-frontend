# Cadastro de Clientes — Frontend

Interface web para gerenciamento de clientes, desenvolvida no curso Desenvolvimento de Interfaces Web com JavaScript da Universidade do Trabalho Digital (UTD).

## Objetivo

Oferecer uma experiência simples para consultar e administrar cadastros de clientes, consumindo a API do projeto backend.

## Funcionalidades

- Listagem de clientes.
- Cadastro de novos registros.
- Edição de dados existentes.
- Exclusão de clientes.
- Validação e feedback visual durante as operações.

## Tecnologias

- React
- Vite
- JavaScript
- CSS
- Integração com API Node.js / MySQL

## Como executar

```bash
npm install
npm run dev
``

Configure a URL da API no arquivo de ambiente local conforme necessário. Nunca publique credenciais ou variáveis sensíveis.

## Qualidade

Cenários relevantes para validação incluem campos obrigatórios, formatos inválidos, mensagens de erro da API, estados de carregamento, atualização da lista após operações CRUD e responsividade da interface.
